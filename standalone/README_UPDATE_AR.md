# تحديث برنامج تشغيل مصنع الأمير إلى الإصدار 3.1

هذه حزمة تحديث لهوست عليه البرنامج بالفعل. لا تحتوي حسابات أو بيانات أو ملف .env.

1. أوقف خدمة التطبيق على الهوست.
2. خذ نسخة احتياطية من مجلد data كاملًا أو المسار المحدد في DATA_DIR بعد إيقاف الخدمة، وكذلك ملف .env. احتفظ بها خارج مجلد البرنامج.
3. استبدل server.mjs وworkflow.mjs ومجلد public فقط بالملفات المرفقة. يفضّل استبدال public كاملًا لتفادي بقاء ملفات واجهة قديمة.
4. لا تستبدل أو تحذف ملف .env أو مجلد data أو قاعدة alamir.sqlite. لا تنشئ مديرًا أو قاعدة جديدة عند التحديث.
5. شغّل الخدمة بنفس إعداداتها على Node.js 24. ينشئ الخادم جدول inventory إن لم يكن موجودًا، دون حذف سجلات سابقة.
6. افتح البرنامج وحدّث الصفحة بـCtrl+F5. تأكد من ظهور الإصدار v3.1.
7. راجع البيانات الأساسية وقائمة المنتج التام وتكويد الأصناف، ثم كارت الصنف بالمخازن، قبل اعتماد التشغيل الفعلي.

يضيف التحديث بيانات الأصناف والمخازن والأرصدة والصرف والمرتجعات والجودة والتقارير. لا تدخل رصيدًا افتتاحيًا لكمية ظاهرة بالفعل من تذكرة أو إنتاج سابق.

البيانات على رابط التجربة لا تنتقل إلى الهوست، ونشر رابط التجربة لا يحدّث موقعك. الحزمة تستخدم ملفات الواجهة الجاهزة ولا تتطلب npm install للتشغيل.

للرجوع إلى النسخة السابقة، أوقف الخدمة أولًا. احتفظ أيضًا بنسخة احتياطية من الحالة الحالية قبل الاستعادة؛ استعادة قاعدة النسخة الاحتياطية ستفقد الحركات التي أضيفت بعدها. استعد ملفات البرنامج وقاعدة البيانات المتوافقة معها بعد مراجعة هذه الحركات.
