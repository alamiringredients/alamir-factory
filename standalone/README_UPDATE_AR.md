# تحديث برنامج تشغيل مصنع الأمير إلى الإصدار 4.5.0

هذه حزمة تحديث لهوست عليه البرنامج بالفعل. لا تحتوي حسابات أو بيانات أو ملف .env.

1. أوقف خدمة التطبيق على الهوست.
2. خذ نسخة احتياطية من مجلد data كاملًا أو المسار المحدد في DATA_DIR بعد إيقاف الخدمة، وكذلك ملف .env. احتفظ بها خارج مجلد البرنامج.
3. استبدل server.mjs وworkflow.mjs ومجلد public فقط بالملفات المرفقة. يفضّل استبدال public كاملًا لتفادي بقاء ملفات واجهة قديمة.
4. لا تستبدل أو تحذف ملف .env أو مجلد data أو قاعدة alamir.sqlite. لا تنشئ مديرًا أو قاعدة جديدة عند التحديث.
5. شغّل الخدمة بنفس إعداداتها على Node.js 24. ينشئ الخادم جدول inventory إن لم يكن موجودًا، دون حذف سجلات سابقة.
6. افتح البرنامج وحدّث الصفحة بـCtrl+F5. تأكد من ظهور الإصدار v4.5.0.
7. راجع البيانات الأساسية وقائمة المنتج التام وتكويد الأصناف، ثم كارت الصنف بالمخازن، قبل اعتماد التشغيل الفعلي.

يضيف التحديث بيانات الأصناف والمخازن والأرصدة والصرف والمرتجعات والجودة والتقارير. لا تدخل رصيدًا افتتاحيًا لكمية ظاهرة بالفعل من تذكرة أو إنتاج سابق.

البيانات على رابط التجربة لا تنتقل إلى الهوست، ونشر رابط التجربة لا يحدّث موقعك. الحزمة تستخدم ملفات الواجهة الجاهزة ولا تتطلب npm install للتشغيل.

للرجوع إلى النسخة السابقة، أوقف الخدمة أولًا. احتفظ أيضًا بنسخة احتياطية من الحالة الحالية قبل الاستعادة؛ استعادة قاعدة النسخة الاحتياطية ستفقد الحركات التي أضيفت بعدها. استعد ملفات البرنامج وقاعدة البيانات المتوافقة معها بعد مراجعة هذه الحركات.

تصحيح 3.8: منع تداخل أوامر Bulk أصبح لكل كود منتج نصف مصنع على حدة؛ يسمح بمنتجات مختلفة خلال نفس الأسبوع. لا يغير الأوامر القديمة أو أرصدتها.

تحديث 3.8: أصناف الماستر وBOM مدمجة في workflow.mjs وملفات الواجهة. لا يحتاج تحميل الملف يدويًا بعد التحديث. راجع تبويب تعارضات الأكواد ووصفات BOM في البيانات الأساسية، واستخدم تحميل BOM للأوامر القديمة عند الحاجة. لا ينشئ التحديث أرصدة افتتاحية أو حركات صرف تلقائية.

تحديث 3.9: الدورة الجديدة تتطلب التحويل إلى مخزن الإنتاج قبل الصرف، واعتماد جودة البلك قبل إنشاء أمر التعبئة، وتسجيل أوزان العبوات قبل جودة المنتج المعبأ. الملصقات مستقلة تمامًا عن حركات المخزون والإنتاج. الأرصدة الوهمية تضاف لمساحة التجربة فقط؛ الأوامر القديمة تحتفظ بقواعدها. راجع PRODUCTION_CYCLE_V3_9.md وRELEASE_V3_9.md.

إصدار 4.0 يحافظ على الكميات والحركات القائمة؛ لا تعِد إدخال الأرصدة ولا تحذف data أو DATA_DIR. عرّف مراكز التكلفة والخطوط وأدوار المسؤولين، وراجع OPERATIONS_CONTROL_V4_0.md قبل إنشاء أوامر جديدة. الأوامر القديمة لا يعاد اعتمادها ولا يعاد حسابها. لا توجد قيود مالية أو أسعار مخزون مفترضة في هذا التحديث.

إصدار 4.1: واجهة منظمة، فصل البلك والتعبئة، وملف جاهزية الماكينات للجودة. الكميات والحركات القائمة محفوظة. راجع WORKSPACE_V4_1_AR.md، وعرف الماكينات التابعة لكل خط من شاشة الصيانة؛ لا يوجد تغيير في قاعدة البيانات أو كلمات المرور مطلوب عند التحديث.

إصدار 4.2 يضيف لوحة القيادة كصفحة بداية؛ لا يغير الأرصدة أو الحركات أو إعدادات الحسابات. ارفع الواجهة الجديدة مع ملفات الحزمة، وراجع DASHBOARD_V4_2_AR.md.

إصدار 4.2.1: نقل الوصول السريع إلى أعلى لوحة القيادة.


إصدار 4.3: فصل استلام الثمار عن الخامات ومواد التعبئة، وإلغاء اعتماد المخازن لاستلام الثمار. صافي التذاكر المكتملة غير المستخدمة يدخل الأرصدة بالحوض تلقائيًا؛ لا تعِد إدخاله كرصيد افتتاحي. الحركات المخزنية السابقة ومواقعها وأكوادها محفوظة. راجع RELEASE_V4_3.md للدورة الجديدة وSOURCE_SHEET_V4_3.md لمطابقة الشيت. بيانات الجودة غير المطابقة تظل تحذيرات، والقبول أو الرفض للجودة مع توثيق السبب. لا يتغير DATA_DIR أو ملف البيئة أو حسابات المستخدمين عند التحديث.


إصدار 4.3.1: البحث الشامل أعلى النظام واختصار Ctrl+K. البحث وفتح النتائج لا يغيران الأرصدة. راجع RELEASE_V4_3_1.md. السورس وحزمة الهوست من نفس النسخة المنشورة.


إصدار 4.3.2: رقم الباتش في شاشة الملصقات قائمة اختيار من باتشات الصنف المسجلة، ويمكن تصفيتها بأمر التعبئة. قبل الإنتاج يظهر رقم تلقائي لأمر التعبئة المفتوح؛ بعد حجز الملصقات يستخدمه النظام للناتج الأساسي تلقائيًا إذا ترك رقم الباتش في تسجيل الناتج فارغًا. إعادة طباعة الملصقات السابقة تحفظ أرقامها والباركود كما هي. راجع RELEASE_V4_3_2.md.


إصدار 4.4.0: الخصم المعتمد بحد أقصى 20%، واسم القائم بالفحص بدل رئيس الجودة، وإلغاء رقم اللوط في فحص الثمار. تأكيد الخصم يتطلب اسم القائم بالتعديل وإقرار الانتقال للتفريغ. اعتماد الجودة بنتيجة الفحص الكاملة يسبق استلام البلك والمنتج المعبأ والخامات ومواد التعبئة بالمخزن. لا تتم إعادة تهيئة الأرصدة. راجع RELEASE_V4_4_0.md لتسلسل الإجراءات والتعامل مع المراحل المعلقة السابقة. استبدل واجهة البرنامج وworkflow.mjs معًا ثم حدث المتصفح بـCtrl+F5.


إصدار 4.4.1: إدخال واعتماد فحص البلك والمنتج المعبأ أصبح خطوة مستقلة داخل «الجودة ← متابعة فحوص الجودة». اختر نوع الفحص والأمر والباتش لإظهار النموذج في نفس الصفحة. نتائج الأمر تظل مرتبطة به، والاستلام المخزني بعد قبول الجودة. راجع RELEASE_V4_4_1.md.

إصدار 4.4.2: تحديث شعار ALAMIR INGREDIENTS في واجهة التشغيل، وتذكرة السائق، ومستندات المخازن، وملصقات المنتج. ملف الشعار الجديد داخل public/brand؛ ارفع مجلد public المرفق ثم حدّث المتصفح. راجع RELEASE_V4_4_2.md.

إصدار 4.5.0: داشبورد التشغيل بالألوان الفاتحة، وفلاتر الثمار والفترة، ورسوم الاستلام والبلك والتعبئة والجودة والمخزون والشفتات. الكميات والأرصدة من سجلات النظام؛ لا تُضاف بيانات المعاينة إلى قاعدة البيانات. ارفع public المرفق وحدّث المتصفح. راجع RELEASE_V4_5_0.md.
